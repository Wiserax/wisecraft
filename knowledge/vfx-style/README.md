# The house VFX style: hand-drawn 2.5D, stylised hybrid CGI

The producer's reference set for every visual effect: 2D hand-drawn effect shapes blended with 3D, bold
silhouettes, flat cel colour, dark ink shapes, sharp timing. The rules that turn it into checks are in
[`skills/game-vfx/references/style.md`](../../skills/game-vfx/references/style.md); the **game-vfx** skill
uses this set when a search finds nothing better, and as the bar every effect is judged against.

## The images stay on this machine
`refs/` holds ten images the producer picked on Pinterest (2026-10-20). They are other artists' work, so the
folder is gitignored: never commit, push, ship or trace them. A fresh clone has no `refs/`; ask the producer
for the set, or gather a new one with the game-vfx skill.
