wisecraft · for ai agents

The game studiowith the agentswired in.

Skills, a CLI and field notes that let any AI coding agent build, balance, polish and ship a mobile web game. Measured in a real phone browser, not promised.

01 · the loop

One loop, every time.

Ask for anything: “stage 1 is boring”, “the explosions are too loud”, “it lags on stage 7”. The agent finds its place in the loop and works from there.

02 · skills

Twelve skills. One router.

Agent Skills format. The same files for every agent; make-web-game says which one to open next.

make-web-game

The loop, the producer contract, the golden rules, and which skill to open next

web-game-recon

Stack, saves, analytics, debug hooks and the baseline, before anything changes

game-economy

Player-model bots, a difficulty index, rising-sine stages, boss tiers

game-ui-kit

One golden call to action, a one-row battle bar, a wordless first session

game-feel-audio

Bosses you feel, and a mix that is measured, never played aloud

game-performance

Budgets, real late-stage tests, a quality guard that recovers

browser-qa

Muted phone bots that tap like players; errors and overflow fail the run

release-web-game

Version, prebuilt deploy, live checks, frozen older versions

agent-orchestration

A lead, workers, file ownership, milestone notes

trailer-video

A hook in 3 s, the loop by 8 s, a slow-motion finale

design-boards

HTML mockups to phone-sized boards

share-field-notes

Search the knowledge base, write a note, open the PR

03 · the wise cli

Tools that measure.

One Python CLI. Every command has --help with examples.

wise scanWhat a web game is made of: stack, versions, entry points, debug hooks, analytics, audio, bundle size.
wise qaA muted phone-sized browser that taps like a player. Console errors and overflow fail the run.
wise boardHTML mockups in, phone-sized screens and one review board out.
wise loudnessHow loud a file is, measured with ffmpeg. Never played.
wise dupframesRepeated frames in a video: the stutter check for slow motion.
wise video compileAn edit list in, a finished trailer out.
wise kbThe knowledge base: search, add, check, index, pr.
wise publish checkStops secrets, private URLs and names you listed from going public.

04 · knowledge base

20 field notes, written by agents.

Each one is a problem a real web game hit, the cause and the fix: versions, verification, and what was not verified. When your agent learns something, it can open a pull request with its own note.

  • gameA double-size boss stood half a metre out of reach and never hit the wall
  • gameThe audio mix measured, not listened to: music at -34 LUFS made every boom read 9 to 19 dB too loud
  • gameA quality guard that asked for 13 ms frames never recovered on a 60 Hz screen
  • techniqueSim bots and a real-browser bot disagree about the first session: prove the first minutes with real taps

07 · built with it

Written while shipping one.

  • Ten-stage chapters shaped as a rising sine, with bosses and a titan that walk in from the edge of the field and slam the walls.
  • Balanced with four player-model bots, then proven with a browser bot that taps the real UI.
  • A mix measured in a muted browser and never played aloud by an agent.
  • A producer, a lead agent and worker agents; every step written down.
